# Sdorica 最佳操作演算法模擬器 (Sdorica Optimal Move Algorithm Simulator)

這是一個基於 Python 開發的專案，旨在模擬雷亞遊戲《Sdorica 萬象物語》中的核心戰鬥機制——「魂盤操作」，並實作演算法以尋求特定盤面下的最佳解。開發過程中主要由使用者設計核心流程與邏輯架構，並由 AI (如gemini)實踐程式碼細節。

本專案目前為純粹優先序驅動 (Pure Priority Driven) 的決策模式，專注於模擬單回合收益最大化的貪婪策略。
## 專案核心

### **1. 魂盤模擬器 (`soul_board_simulator.py`)**

當一個操作執行時，模擬器會依序執行以下邏輯：

1. **驗證 (Validation)**：檢查選擇的魂芯座標是否連通、顏色是否一致，並比對是否符合角色技能（如 1消、2消、4消方形等）。  
2. **消除 (Elimination)**：將被選中的座標標記為 EMPTY。  
3. **向左重力 (Leftward Gravity)**：  
   * 遍歷每一列（Row）。  
   * 將非空魂芯全部向左擠壓，填補消除產生的空隙。  
4. **右側回填 (Right-side Refill)**：  
   * 計算每列擠壓後留下的右側空位。  
   * 根據隨機種子或預設規律，從右側生成新的魂芯填滿盤面。  
5. **視覺化 (Visualization)**：輸出帶有 ANSI 彩色的 2x7 矩陣至終端機。


### **2. 決策演算法 (`move_algorithm.py`)**

目前的演算法採用**單步貪婪演算法 (Pure Greedy)**。

* **決策邏輯**：演算法依照 priority\_list（優先序列表）進行排列組合。  
* **評分方式**：當多個操作同時存在時，演算法將選擇在優先序表中分數最高的項目；若分數相同，則依照掃描順序執行。

### **3. 實驗控制器 (sdorica_lab_api.py`)**

作為使用者與底層邏輯的中介 API，提供：

* **實驗環境設定**：支援固定隨機種子 (Seed)，確保測試結果可重現。  
* **自動化測試**：可連續執行指定回合數，並統計總分與平均分。  
* **資料格式輸出**：提供純文字的盤面狀態字串，方便串接其他分析工具。

## 快速開始 (Quick Start)

### **需求環境**

* Python 3.6 或以上版本。

### **執行測試**

最簡單的方式是直接執行控制器 (Controller)，它會跑一個範例實驗：

``` python
python sdorica_api.py
```

您將在終端機中看到彩色的魂盤輸出，以及演算法每回合的決策過程

## **檔案結構**

* `soul_board_simulator.py` (模擬器核心)  
  * 定義 `SoulOrb` 與 `SoulOrbSimulator` 類別。  
  * 包含所有形狀模板 (`SHAPE_TEMPLATES`) 與物理邏輯。  
* `sdorica_algorithm.py` (演算法邏輯)  
  * 定義 `SdoricaSolver` 類別。  
  * 負責窮舉所有合法步數 (`find_all_valid_moves`) 並計算分數。  
* `sdorica_api_controller.py` (主程式/API)  
  * 定義 `SdoricaController` 類別。  
  * 整合模擬器與演算法，管理遊戲狀態與統計數據。

## **快速開始**

1. 確保已安裝 Python 3.x。  
2. 執行 sdorica\_lab\_api.py 啟動預設實驗：  
   python sdorica\_lab\_api.py

3. 觀察控制台每 10 步跳出的進度報表，分析當前權重設定下的操作效率。
